# 販売支援システム (PSYS)

株式会社 健康食品ロイヤル社様向け「得意先管理・得意先別集計業務システム」のWebアプリケーションです。  
Django 5.1（Python 3.13）および MySQL 8.3 をベースに構築され、視認性と操作性に優れたモダンなダークテーマUIを備えています。

---

## 主な機能一覧

### 1. 共通・認証システム
- **従業員ログイン / ログアウト**: 従業員番号（6桁）とパスワードによる認証、セッション管理
- **アクセス制御ガード**: ログイン必須デコレータ（`@login_required_psys`）による未認証アクセスの自動リダイレクト保護
- **従業員新規登録**: 新規利用従業員のアカウント発行

### 2. 得意先管理サブシステム
- **得意先一覧**: 登録されている有効顧客（論理削除除外）の全件表示、詳細・変更・削除への画面遷移
- **得意先検索**: 得意先コードによるリアルタイム照会、該当なしエラーハンドリング
- **得意先新規登録**: `customer_numbering` テーブルと連携したトランザクション排他ロック（`select_for_update`）による自動採番（`RA0016`〜）
- **得意先変更**: 登録済み得意先情報の修正・更新
- **得意先削除**: 過去の受注・売上データを安全に保持する**論理削除（`delete_flag = 1`）**

### 3. 得意先別集計サブシステム
- **月別受注集計**: 年・月を指定した得意先別売上合計・総合計（税込）の集計
- **年次受注集計**: 年間売上合計および総合計の算出
- **商品別受注集計**: 得意先ごとの商品別受注数量・単価・小計・総合計の集計

## 動作要件・技術スタック

- **言語**: Python 3.13
- **Webフレームワーク**: Django 5.1
- **データベース**: MySQL 8.3 (`psysdb3`) / SQLite（テスト用）
- **フロントエンド**: HTML5, CSS3, Bootstrap 5.3（レスポンシブ・ダークテーマ）
- **主要ライブラリ**: `mysqlclient`, `sqlparse`, `asgiref`

## 起動手順

### 1. リポジトリのクローン
```powershell
git clone https://github.com/0xRIA/-.git
cd -
```

### 2. 仮想環境の作成とパッケージのインストール
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. データベースのセットアップ (MySQL)
MySQLに接続し、データベースの作成と初期データを投入します：
```sql
CREATE DATABASE psysdb3 CHARACTER SET utf8mb4;
```
```powershell
mysql -u root -p psysdb3 < psysdb.sql
```

> **設定の確認**:  
> `config/settings.py` 内の `DATABASES` 設定（ユーザー名・パスワード）がローカルのMySQL環境と一致していることを確認してください。

### 4. 開発サーバーの起動
```powershell
python manage.py runserver
```
起動後、ブラウザで [http://127.0.0.1:8000/](http://127.0.0.1:8000/) にアクセスしてください。
